# 도깨비 소녀와 함께 — 웹 프로토타입

[네이버 게임 라운지](https://game.naver.com/lounge/Dokkaebi_Girl/home)의 모바일 방치형 수집 RPG
「도깨비 소녀와 함께」(Apex Esports Network Limited)를 역설계해 핵심 루프를 단일 HTML 파일로 재구성한 습작.

## 실행

`index.html`을 브라우저로 열면 끝. 빌드·의존성 없음. 진행 상황은 `localStorage`에 저장된다.

## 원작 화면 구조 (공식 스크린샷 기준)

1차 버전은 텍스트 설명만 보고 만들어 1:1 정면 전투에 이모지를 쓴, 전혀 다른 물건이 나왔다.
Google Play 공식 스크린샷을 확인해 화면 구조를 다시 맞췄다.

| 원작 | 프로토타입 |
|---|---|
| 로비: 중앙 대형 캐릭터, 좌우 세로 아이콘 레일, 상단 자원+전투력, 하단 6칸 독, 도전 배너·세계채팅·서버번호 | 동일 구조로 재현 |
| 전투: 사이드뷰 필드에서 파티 다수 vs 몬스터 다수 자동 전투 | 파티 4 vs 웨이브 5마리, 몹이 걸어와 자기 자리에서 교전 |
| 하단 원형 스킬 아이콘 + AUTO 토글 + 나가기 | 몽둥이 강타 + 파티원 스킬, 방사형 쿨타임, AUTO 토글 |
| `CRITICAL BREAK` / `OVERPOWER` 데미지 연출, 콤보 | 콤보 10/30 구간에서 동일 태그 연출 |
| 월드보스: 보스 배너 + 카운트다운 + HP 게이지 + 기여도 랭킹 4칸 | 동일 |
| 영지: 탑뷰 맵에 건물 Lv, 낚시 미니게임 | 낚시터·농장·연구소 + 타이밍 낚시 |
| 숫자 단위 `K/M/B/E` | `K/M/B/T/AA…` |

**옮기지 않은 것**: 학생회(길드), 아레나 PvP, 출항, 코스튬/직업, 스토리, 결제.

**아트**: 원작 캐릭터 에셋은 저작권이 있어 쓰지 않았다. 같은 치비 톤으로 SVG를 직접 그렸다
(머리·의상·포인트 3색 팔레트 + 여우/오니/고양이 귀 변형).

## 설계 노트 — 왜 환생을 넣었나

원작에 없는 축을 하나 더했다. 이유는 수치에서 나왔다.

장비 강화는 비용이 지수(×1.10/레벨)로 오르므로 도달 가능 레벨은 골드의 로그,
따라서 **DPS는 층수에 대해 선형**으로만 자란다. 반면 몬스터 HP는 **지수(×1.13/층)** 다.
시뮬레이션 결과 어떤 파라미터를 써도 60층 부근에서 완전히 정체했다.

```
HP^1.13 골드^1.15 비용^1.10 → 10분 34층 / 30분 40층 / 60분 44층 / 8시간 60층 (정체)
```

캐릭터 승급·호감도는 **상수 배율**이라 벽을 8층 정도밖에 못 민다.
원작은 이 지점을 뽑기와 결제로 메우지만, 여기서는 장르의 정공법인 프레스티지로 풀었다 —
정수 1개당 공격력 ×1.18(지수), 25층 초과분의 0.6배 지급.

| 정수 배율 | 30분 | 1시간 | 2시간 | 4시간 |
|---|---|---|---|---|
| **×1.18** | 60층 | 100층 | 161층 | 180층에서 안정 |
| ×1.22 | 74층 | 139층 | 336층 | 687층 (폭주) |
| ×1.26 | 86층 | 179층 | 575층 | 2190층 (폭주) |

×1.18은 층당 실효 성장률이 HP 성장률과 거의 균형을 이뤄, 계속 나아가되 폭주하지 않는다.
위 수치는 **캐릭터 성장을 전부 제외한 하한선**이라 실제 플레이는 더 빠르다.

## 주요 수식

```js
mobHp(층)   = 60  × 1.13^(층-1) × (보스면 ×8)      // 웨이브 5마리가 나눠 가짐
mobGold(층) = 14  × 1.15^(층-1) × (보스면 ×10)
장비비용     = base × 1.10^(레벨-1) × (1 - 무쇠 특성)
공격력       = (기본+장비+파티) × (1+세라 특성) × 1.18^정수 × (1+0.04×(계정Lv-1))
DPS         = 공격력 × (1 + 치명확률 × (치명피해-1))
정수         = floor(max(0, 최고층 - 25) × 0.6)
```

## 구현 노트 — 브라우저 때문에 생긴 것들

- **rAF는 백그라운드 탭에서 완전히 정지한다.** 그래서 웨이브 재스폰을 `setTimeout`이 아니라
  게임 루프가 세는 카운트다운(`B.respawn`)으로 옮겼다. 타이머도 같이 얼어붙기 때문이다.
- **탭 복귀 시 방치 보상 정산**을 `visibilitychange`에 걸었다. 페이지 로드 때만 정산하면
  탭을 몇 시간 방치했다 돌아왔을 때 그 공백이 통째로 사라진다.
- **월드보스 타이머는 실제 경과 시간 기준**이다. 틱 수로 세면 throttle된 탭에서 30초가 늘어진다.
- **자동 평타는 0.3초씩 모아 한 방으로 낸다.** 매 프레임 때리면 한 대가 소수점이라 `0`으로 찍힌다.
- **몹은 자기 자리까지 걸어온 뒤에만 맞는다.** 이 판정이 없으면 화면 밖에서 전멸해 전투가 안 보인다.
